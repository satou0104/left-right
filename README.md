# 左右落下ゲーム

iPhone対応の左右落下ゲームです。

## 遊び方

- **黒文字**: 文字通りに操作（「左」→左キー/左スワイプ、「右」→右キー/右スワイプ）
- **赤文字**: 位置で判断（左列→左キー/左スワイプ、右列→右キー/右スワイプ）

## 操作方法

### PC
- ←→キーで操作

### iPhone/スマートフォン
- 左右スワイプで操作

## ファイル構成

- `index.html` - メインのHTMLファイル
- `game.js` - ゲームロジック
- `style.css` - スタイルシート

## プレイ方法

1. `index.html`をブラウザで開く
2. 「ゲーム開始」ボタンをクリック
3. 落下する文字に合わせて左右に操作

スコアが上がるにつれて、ゲームスピードが上がります！
